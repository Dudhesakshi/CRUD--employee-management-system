# Employee Management System

A web-based Employee Management System that allows users to securely log in and manage employee records through CRUD operations.

## 🚀 Features

- 🔐 User Login
- ➕ Add Employee
- 📋 View Employee List
- ✏️ Edit Employee Details
- 🗑️ Delete Employee
- 💰 Manage Employee Salary
- 📅 Manage Date of Joining
- 📱 Responsive User Interface
- 🎨 Modern and clean UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Java
- Spring Boot
- REST API
- MySQL
- Maven

🔄 CRUD Operations

The application supports:

Operation	Description
Create	Add a new employee
Read	View employee records
Update	Edit employee details
Delete	Remove an employee
🔐 Login

The system provides a login screen where users can enter their email and password before accessing the Employee Management System dashboard.
